# Stock T24 — versión web

Esta rama (`gh-pages`) es la **versión web** de la app, publicada con GitHub Pages:
https://oscaralejandrojuarezleal-beep.github.io/stock-t24-apk/

- Es la **misma app** que la APK: la baja completa desde Apps Script (`T24_apiAppApk`) y la guarda en el navegador.
- La primera vez tarda lo que tarda Apps Script en mandarla; después abre al instante (también sin internet).
- Cuando se publica una versión nueva en Apps Script, aparece "Hay una versión nueva → Actualizar".
- Se puede instalar en el celular o la PC como app (ícono, pantalla completa, sin el cartel de Google).
- Los datos siguen en Apps Script. El link de Apps Script sigue funcionando igual.

Esta rama no toca la APK: la APK se compila sólo desde `main`.
